# Bold Keys 0.7.1 — Inline autofill

- Enable native Android inline autofill from compatible autofill providers.
- Show provider suggestions to the right of the trackpad, replacing predictions while available, without changing keyboard height.
- Scroll between provider suggestions and restore predictions when autofill is dismissed.
- Clear stale suggestions when switching fields or hiding the keyboard.

## Validation

153 debug unit tests and debug lint passed. Android 35 emulator verified provider suggestion rendering, synthetic credential filling and prediction restoration using a test AutofillService. Real Proton Pass behavior still needs phone verification. Instagram and Samsung Notes prediction behavior is unchanged.

This GitHub release is for phone verification before a subsequent Play update.
