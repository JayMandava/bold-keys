# Bold Keys 0.7.0

Adds three optional heritage-inspired keyboard colours: Red, Black & Gold and White & Gold. The original Black, White and Match phone choices remain available, with saved selections preserved. Colours extend to keys, trim, suggestions, symbol and emoji pickers, with the same keyboard layout and typing behaviour.

Appearance uses the current accessible Settings controls. Dark-key colours retain backlight support; the white-key colours stay unlit. These are independent colour interpretations, not official BlackBerry products or exact factory colour specifications. No billing or paid-theme gate is added.

Retains all improvements through 0.6.8, including contextual suggestions, optional on-device models, experimental voice typing and standardized Settings. Version 0.7.0/code 17.
