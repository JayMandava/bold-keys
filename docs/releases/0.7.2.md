# Bold Keys 0.7.2 — Contact and Direct Call Speed keys

- Assign a Speed key letter to open a chosen contact card.
- Assign Direct Call to a specifically selected phone number. Enable Phone permission explicitly; denying or revoking it makes Direct Call do nothing, with no dialer fallback.
- Contact selection uses Android's system pickers without address-book permission. Direct Call keeps a local number snapshot; re-select the number to follow contact edits.
- Block emergency targets and service/USSD/MMI codes, and protect against duplicate call gestures. SIM selection or other system UI may still appear.
- Preserve existing App, Link and Text assignments, ordinary typing, keyboard appearance and gestures.

## Validation and limitations

The reviewed feature passed 184 debug and 184 release unit/regression tests, debug/release lint, 17 release-workflow Python checks and the GitHub Android CI. Seven activity-recreation tests cover picker and permission callbacks with no surprise save or call. Real cloud Android 13/API 33 emulator captures passed at 360 dp/100% text and 320 dp/200% text; all ten captured windows were independently reviewed. Release-specific validation and APK signing are verified by the protected release workflow.

No real calls were made during testing. API 36 runtime testing remains unverified because its Robolectric runtime download was blocked. Real carrier behavior, OEM contact viewers, managed profiles and dual-SIM behavior still require device testing. Direct Call does not guarantee a zero-UI call on every device.

This is a GitHub APK release. Play Store publication is outside this release.
