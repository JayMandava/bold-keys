# Bold Keys 0.6.8

Standardizes explanatory text throughout Settings, including help summaries, expanded instructions, switch descriptions, model descriptions, privacy and credits, onboarding guidance, and offline license text. Descriptions share the same content edge, type style, and justification. Switch and model explanations span the full card width below their controls. Help and external-link labels share the same inset.

Large accessibility text uses the same start-alignment fallback throughout Settings to keep natural word spacing. Radio buttons, titles, status labels, and actions retain their distinct control roles.

No keyboard behavior, model transfers, or privacy guarantees changed. Version 0.6.8/code 16. Protected signing and manual phone validation remain separate release steps.
