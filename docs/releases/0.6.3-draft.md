# Bold Keys 0.6.3 — draft release notes

Proposed release branch: `release/0.6.3`; proposed tag: `v0.6.3`; proposed version: `0.6.3` / code `11`.
Implementation branch: `feat/contextual-local-suggestions`. No tag or release has been created.
The current build still declares production version `0.6.2` / code `10`.

- Improve partial-word suggestions using the preceding word while keeping the two-word strip and deliberate keyboard layout intact.
- Widen bounded candidate coverage, with a small offline English conversational and technical supplement.
- Count known-word preferences and accepted suggestions, and learn useful adjacent word pairs locally.
- Bound local learning and provide “Clear all learning” for words, preferences and pairs; word removal also removes its pairs.
- Preserve editor privacy controls and keep automatic correction thresholds separate from suggestion ranking.
- Serialize spell-engine access and prevent Settings clears from being overwritten by pending or asynchronously loaded state.

- Add Gemma 3 270M QAT as a third optional model, with a pinned publisher revision, checksum and size. Existing model IDs, defaults and saved selections are retained; catalogue-file imports verify integrity. No QAT quality or speed improvement is claimed. Actual cloud download remains unverified.

Keyboard geometry and sizing are unchanged. QAT has limited parent-reported phone smoke evidence; comparative quality and performance remain unmeasured.
