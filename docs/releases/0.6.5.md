# Bold Keys 0.6.5

Speeds up short English dictation in the optional experimental voice feature. It retains the existing 32.2 MB multilingual Whisper Tiny model, uses the whole recording with a context that grows with its length, and keeps the original full context for French and German. No model redownload is needed. The hold-Space/release-to-insert behavior, processing light, permission flow, cancellation, audio wiping and password/editor safeguards remain unchanged.

Voice stays opt-in and local-only, with no online recognition fallback. Existing voice and context-model selections and downloaded files are retained by an in-place update using the same production signing key.

## Verification and limits

The connected OnePlus Nord CE3 Lite comparison used nine unique synthetic short fixtures, each repeated twice; the English subset contained 14 timing samples, including two silence samples, and 12 speech/noise transcripts covering 94 reference words. Native English model-load/inference/free median fell from 4.42 seconds to 1.21 seconds, and nearest-rank p95 from 4.55 seconds to 1.28 seconds. English word-error rate was 25.5% before and 21.3% after on that small corpus. These results do not establish accuracy for a person's voice or accent.

All four French/German transcript comparisons and four additional long/near-limit English comparisons matched baseline exactly. The extra clips were 12.975 and 28.376 seconds; no truncation was observed. The final isolated app passed file-input/JNI, checksum-validation, cancellation and reopening checks, both without QAT and with QAT selected, loaded and scored. App English median validation/load/JNI/inference/free time was 1.23 seconds without QAT and 1.25 seconds with QAT resident. QAT scoring was verified before voice inference; concurrent active scoring was not measured.

The implementation passed 124 app unit tests, build/lint, seven metric tests and independent code/evidence review. The version bump and exact production candidate are checked separately by the protected release workflow before signing and publication. See [benchmark report and raw evidence](../benchmarks/voice-2026-11-06/REPORT.md) for rejected alternatives and measurement details.

Capture-to-editor insertion timing, actual user speech, sustained heat and battery drain remain unmeasured. The feature remains experimental, and inaccurate transcripts are possible.

## Install

Download `bold-keys-0.6.5.apk` and verify it against `SHA256SUMS-0.6.5.txt`. Requires Android 13+ on an ARM64 phone. The production APK uses application ID `ai.boldkeys`, version 0.6.5/code 13, and the existing production signing key. An in-place update preserves application data and downloaded models. This GitHub release does not publish to Google Play.
