# Bold Keys 0.6.6

Makes Settings easier to scan while retaining the full guidance behind contextual, accessible details controls. Settings now keeps important privacy, download, experimental, and learning-deletion warnings visible without opening details.

The Context model screen shows every model state, separates model size from notes, and uses clear download, cancel, and remove actions. Voice settings are grouped by enablement, model actions, privacy, and optional instructions. Choice controls retain compact segmented controls at normal size and wrap at large text or narrow widths. The personal-dictionary input and its Add action now have separate rows for readable large-text layouts.

No keyboard behavior, preferences, model transfer behavior, or privacy guarantees changed. This release is version 0.6.6/code 14. Signing, protected release checks, and phone validation are performed separately before publication.
