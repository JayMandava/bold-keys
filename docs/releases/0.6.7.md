# Bold Keys 0.6.7

Long, full-width Settings explanations and expanded help now use justified alignment. Short notes and switch descriptions retain natural start alignment. Above 130% system text size, explanations also use start alignment to avoid stretched word spacing with large accessibility text.

No keyboard behavior, preferences, model downloads, or privacy guarantees changed. This release is version 0.6.7/code 15. Protected signing and phone validation remain separate release steps.
