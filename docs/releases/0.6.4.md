# Bold Keys 0.6.4

Adds optional, experimental on-device voice typing. It is off by default. Under Experimental, enable voice, grant microphone permission and separately download the 32.2 MB Whisper Tiny model. Audio remains on device; there is no online recognition fallback. Model downloads are SHA-256 verified; weights are not bundled, and license notices are included.

Hold Space to speak. Release to transcribe and insert directly into the same eligible editor. The spacebar glows green while recording and slowly flashes while transcribing. There is no extra voice panel, preview or Insert/Cancel button. Slide off Space to discard. Typing, cursor/editor changes, keyboard dismissal and opting out discard pending work. Password fields cannot activate voice. Dictation never invokes Send or autocorrect. Regular typing, autocorrect and double-space punctuation retain their existing behavior. Screen readers use the existing Space key actions; reduced-motion settings use a steady processing light.

## Verification and experimental limits

The voice application source at `56f064b5` passed 124 tests per debug/release variant, cloud builds/lint and API 33 emulator gesture/UI/typing checks. A connected OnePlus phone passed actual offline acoustic synthetic-speech automatic insertion, processing flashes, cancellation, editor/password safety and typing regressions. Earlier phone tests verified model download/hash. The 0.6.4 version bump and production candidate are checked separately by the protected release workflow before signing/publication.

Synthetic-speech recognition was inaccurate. Human speech, multilingual quality, formal performance and simultaneous QAT/Whisper loading remain unverified. Cloud model access returned HTTP 403; real inference was verified on the phone, not the emulator. A cloud external-app editor recording check was inconclusive. This feature remains experimental pending further phone testing.

## Install

Download `bold-keys-0.6.4.apk` and verify it against `SHA256SUMS-0.6.4.txt`. Requires Android 13+ on an ARM64 phone. The standard production APK uses application ID `ai.boldkeys`, version 0.6.4/code 12, and the existing production signing key for update continuity. Voice remains optional after updating. Separate review packages are not replaced. This GitHub release does not publish to Google Play.
