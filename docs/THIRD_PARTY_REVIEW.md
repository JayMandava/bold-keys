# Third-party terms and data provenance review

This is an evidence ledger, not a legal clearance or a new third-party license grant. The unresolved Norvig/Tatoeba next-word tables have been replaced in this local review candidate using pinned CC0 text alone. Spelling dictionaries are unchanged byte-for-byte and now rebuild from pinned inputs. Prediction-quality trade-offs, ordinary third-party/store terms, signing and device QA still require owner review before shipping. No workflow was dispatched.

Only the three bounded Sentence Collector files are used (about 9.3 MB raw combined). Large Wiki, Europarl and other bulk files are excluded. The project's pinned sentence guidance describes community validation of Sentence Collector text, while warning that some older bulk imports can contain unsuitable or rights-restricted material. That is a reason to keep scope narrow and retain provenance; CC0 is not a warranty of every donor's rights, privacy or text quality. No voice/audio data, account, dataset download agreement or click-through acceptance was used.

The current corpus-only generator uses no FrequencyWords word membership/counts, prior CC BY-SA seed file, previous table rows, or held-out files. It ranks only adjacent counts and unigram prompt counts from the pinned CC0 Sentence Collector input. Previous seed/table contributions keep their CC BY-SA terms and are not relicensed. Current project rights in newly generated corpus-only tables are dedicated under CC0; underlying Common Voice CC0 remains unchanged. Runtime English spelling-style filtering still uses the retained spelling dictionaries, and those dictionaries still carry CC BY-SA obligations. See `PREDICTION_COVERAGE_REVIEW.md` and `DATA_DISTRIBUTION_REVIEW.md`; this is technical generation independence, not blanket legal clearance for the application.

The prior English table's Norvig corpus grant and the prior French/German tables' Tatoeba contributor-attribution questions were **not retrospectively cleared**. Those data are absent from current build inputs and artifacts. They remain only in existing Git history and are read locally for aggregate comparison, without exporting their rows or predictions. The old French/German builders now reject sentence/pair arguments and only build pinned word dictionaries; production workflows and APK/AAB verifiers check the replacement-data hashes and packaged notices. There is no fallback to old tables.

A permissive conversion-repository code license would not replace the base-model terms.

The app now displays model terms/use-restriction information and an external terms link before the download description. No agreement is accepted on the owner's or user's behalf, no model is downloaded by this task, and no model grant is changed. Owner/legal review must decide how direct third-party downloads and any future model distribution meet the applicable terms. Imported models keep their own licenses and are not licensed by the app.
