Bold Keys filters word forms and converts data to tab-separated word/count tables.
French/German processing also filters accent/umlaut variants. The pinned 2018
input files and explicit English adjustments reproduce all three dictionaries
byte-for-byte; recipe and source hashes are in tools/data and data-provenance.json. Upstream content

NEXT-WORD DATA
English, French and German hints use Mozilla Common Voice Sentence Collector
contributors' text under CC0 1.0 Universal, plus small newly authored project chat
choices. Generation also uses the CC BY-SA 4.0 FrequencyWords dictionaries to
select and rank followers. The generated data and new project seed contributions
conservatively retain CC BY-SA 4.0 terms; underlying Common Voice material remains
CC0. The app/generator code remains Apache-2.0. CC0 itself imposes no attribution
or share-alike condition; the Common Voice credit here is voluntary.
Generated-data license: https://creativecommons.org/licenses/by-sa/4.0/
Source project: https://github.com/common-voice/common-voice
Snapshot: 70dde553e48d7d0da452ba4ba070c001f65db88c
Selected files: server/data/en/sentence-collector.txt,
server/data/fr/sentence-collector.txt, server/data/de/sentence-collector.txt.
The data subtree LICENSE and English local LICENSE both contain CC0 1.0,
reproduced in CommonVoice-CC0.txt. The repository code license is not being used

Bold Keys normalizes accents/apostrophes/case, deduplicates prompts, counts word
pairs, filters against its dictionaries, ranks followers and adds explicitly
identified project chat choices. Project seeds: tools/data/prediction_seeds.json.
Exact input URLs, hashes, recipe and asset hashes: data-provenance.json.
No Norvig/Tatoeba-derived next-word tables are included in this candidate.
